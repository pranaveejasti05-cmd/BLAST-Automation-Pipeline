# BLAST-Automation-Pipeline
A Python-based automated BLAST sequence analysis web application using Biopython and Streamlit.

BLAST (Basic Local Alignment Search Tool) is an important bioinformatics tool used to identify similarities between DNA and protein sequences. It compares a query sequence against biological databases to identify matching or related sequences. It is widely used in gene identification, genome annotation, evolutionary studies and protein analysis. This project aims to automate sequence similarity searching using Python, Biopython and Streamlit.
